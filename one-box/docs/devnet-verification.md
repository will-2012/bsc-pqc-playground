# 本地开发链验收

2026-10-27 在 macOS arm64 上实测。Go 1.26.4，Foundry 1.2.1；Linux 尚未实机验证。

源码基线：

- BSC v1.8.1：`947ba1cb1ef05d4a5f71b738113a3d8b4c16f6b7`。
- 创世合约：`234e3685ec309624f0fbef41043ae117caebc853`，与此前 `node-deploy` 实验的基础版本一致。
- 两个 submodule 均未修改；本地开发参数只应用于运行目录中的合约副本。

| 项目 | 实测结果 |
| --- | --- |
| 从源码构建 | 通过；二进制显示 BSC 自身的提交号，而非主仓库提交号 |
| 创建环境 | 随机生成 3 套 ECDSA/BLS/P2P 身份和 5 个实验账户 |
| 创世资金 | 仅给本次生成的验证者、实验账户充值；移除了上游固定预充值账户 |
| 分叉 | 实际跨越 Fermi、Pasteur、Jenner，安装 Jenner PaymentLane 合约；核对全部节点实际分叉时间 |
| 共识 | 三节点共同高度区块 hash 相同；出块、BLS 最终性在每个节点持续推进 |
| 验证者注册 | 三笔 StakeHub 注册交易成功，检查回执状态 |
| 实验账户转账 | 使用生成的 keystore 签名，收款余额变化正确，三节点回执一致；普通转账 21,000 gas |
| 换配置、重启 | 修改 RPC/P2P 端口和缓存后重启，再恢复默认配置；密钥、创世 hash、分叉时间和历史交易保留 |
| 客户端替换 | 更换为另一份 SHA-256 不同的 v1.8.1 构建后恢复出块和最终性；保留旧二进制、链数据和历史交易 |
| reset | 重新生成全部身份、创世状态和分叉计划；旧交易不再存在；配置保留，新链重新注册、出块和转账成功 |
| 配置复用 | 用同一套脚本、模板生成另一环境，改变端口、实验账户数量和初始余额；生成后核对余额，未启动该辅助环境 |
| 本地文件 | 密钥、密码、构建产物被 Git 忽略；生成的密钥和密码文件无组/其他用户访问权限 |
| 自动检查 | 9 项配置、RLP、端口占用和 reset 保护测试通过 |

客户端替换测试验证的是**相同协议版本的二进制替换流程**，不代表已验证跨版本升级或数据库降级。

## 复查

```bash
python3 -m unittest discover -s one-box/tests -v
./tools/one-box check
python3 one-box/tests/smoke.py
```

本次环境的区块、最终性和交易证据位于 `one-box/.runtime/devnet/health.json`、`registrations.json`、`smoke-result.json`。这些属于本地运行数据；reset 后重新生成。
